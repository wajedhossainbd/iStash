# Name check and the emroze.dev approach

## Chosen name: Stowaway
No notable software conflict found (only an old free Mac game). It names the core feature: app data stows away on an
external drive while the app keeps working. stowaway.app already has nameservers (registered); github.com/stowaway is
taken, so use an org/user repo such as `<you>/stowaway`.

Rejected: Roomy (an existing paid Mac cleaner, same category), Headroom (Mac App Store podcast app + GitHub menu-bar
apps), Harbor (App Store app + well-known container registry), Overflow (App Store launcher), Breathe (Apple +
wellness apps), Offload (Apple's iOS term, crowded), Spacious (old Spaces tools). Minor conflicts: Dockyard, Ballast.
Not checked: trademarks, Mac App Store search directly.

## emroze.dev (Abdullah Emroze, Dhaka)
Apps: TidyMac (Mac utility), Framely (store screenshots), PhotoRelay (phone → computer photos), Hushtype (iOS AI
keyboard, soon), DocScanner (soon), Pen Fight (web game).
Approach: one job per app, runs on your device, no account, no ads or tracking, built to last.
Every app page uses the same template: Overview / Privacy / Support, a hero with download button, version, size,
requirements, a screenshot carousel, a features grid. Direct DMG/APK downloads with install-help pages; free.
